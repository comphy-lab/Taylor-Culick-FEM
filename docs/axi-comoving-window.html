Axisymmetric co-moving window

A hole nucleates in a thin liquid sheet and opens under surface tension. We do not mesh the remaining film. We keep a window of fixed length L and drag that window with the rim. Velocities remain laboratory-frame. The window motion is ALE mesh translation; it is not a Galilean boost of the velocity field.

Physical picture

Axisymmetric Taylor–Culick is hole-opening. Liquid occupies r greater than the hole radius; the midplane is z = 0. We take the initial hole radius X0 = 1, measured in full thicknesses h0, so that the initial condition matches the Basilisk hole (hole0 = 1, cap radius h0/2). Only the upper half-sheet is solved. The mesh is a semicircular cap of radius 1/2, then a flat film of half-thickness 1/2. In the two-dimensional mesh the radial coordinate is stored as mesh_x.

A laboratory-frame annulus with a fixed outer wall must contain the whole trajectory plus the disturbance that runs ahead of the rim. Doubling the run length therefore grows the mesh. The window formulation holds the radial extent of the meshed region fixed at L (default 40, in units of h0) and translates the outer edge with the rim. The film ahead of the rim is unbounded; wall-clock, not the mesh budget, limits how far we can run.

Rim geometry

ALE window, not a moving frame

The coordinate system remains axisymmetric. Mesh coordinates carry the true radius, so the 2πr measure and the hoop terms see physical r. Fluid velocities are laboratory-frame throughout. Only the outer boundary of the meshed region moves.

A radial translation is not a Galilean transformation in axisymmetry (the 1/r metric terms do not translate). We therefore apply no body force. The planar correction −ρ ∂U∂t has no analogue here and must not be copied.

Equations

We non-dimensionalize on the full thickness, with ρ = σ = h0 = 1. The half-thickness is 1/2. Getting this wrong moves the answer by exactly 2. Taylor (1959) and Culick (1960) give the same terminal speed in planar and axisymmetric geometry. Both constants are imported from planar_comoving so the three geometries cannot drift apart.

VTC = 2σ ρh0 = 2
LaTeX 
V_{\mathrm{TC}} = \sqrt{\frac{2\sigma}{\rho h_0}} = \sqrt{2}

The Savva–Bush Ohnesorge number (the driver’s --oh) includes a factor 2 that the coded viscosity does not. We caution that this convention mismatch is large enough to look like physics.

Oh = μ 2ρσh0 μ = 2 Oh , τvis = μh0 2σ = μ2
LaTeX 
\mathrm{Oh} = \frac{\mu}{\sqrt{2\rho\sigma h_0}}
\quad\Rightarrow\quad
\mu = \sqrt{2}\,\mathrm{Oh},
\qquad
\tau_{\mathrm{vis}} = \frac{\mu h_0}{2\sigma} = \frac{\mu}{2}

Window kinematics

The meshed interval is the translating cut

X(t) ≤ r ≤ X(t) + L
LaTeX 
X(t) \le r \le X(t) + L

Two global unknowns close the system: hole radius X and retraction speed U. The far-edge position is not an extra unknown; it is slaved to X.

rtip−X =0 dX dt − U =0 rfar − (X+L) =0
LaTeX 
r_{\mathrm{tip}} - X = 0
\qquad
\frac{\mathrm{d}X}{\mathrm{d}t} - U = 0
\qquad
r_{\mathrm{far}} - (X+L) = 0

Far-edge fluid velocity is laboratory rest: ur = uz = 0 . Mesh velocity of that edge is Umesh = U e^r . The relative flux into the window is therefore U times the far-edge area.

An exact volume identity

The far edge is an inflow of undisturbed film (half-thickness 1/2, at rest). The flux is the product of mesh speed and far-edge area:

dV dt = X˙ ⋅ 2π (X+L) ⋅ 12 = π (X+L) X˙
LaTeX 
\frac{\mathrm{d}V}{\mathrm{d}t}
  = \dot{X}\cdot 2\pi(X+L)\cdot\tfrac12
  = \pi(X+L)\,\dot{X}

This integrates in closed form. No time-step error accumulates from the output cadence:

V(t) = V(0) + π2 [ ( X(t) + L ) 2 − ( X0 + L ) 2 ]
LaTeX 
V(t) = V(0) + \frac{\pi}{2}\Bigl[(X(t)+L)^2 - (X_0+L)^2\Bigr]

Drift of V − Vexpected is as diagnostic here as exact volume conservation is for the lab annulus. A drift indicts the ALE mass balance, the far-edge constraint, or the free-surface kinematics.

We keep the name “co-moving” for the axisymmetric window because it is the sibling of the planar class. Physically the formulation is an ALE translating cut of laboratory-frame axisymmetric Navier–Stokes.

Does the pin hold the tip still?

In the planar problem, yes. One global unknown U is closed by a point constraint at the rim/midplane junction:

xtip = 0  with test function of  U
LaTeX 
x_{\mathrm{tip}} = 0 \qquad\text{(test function of }U\text{)}

Far inflow uses a second multiplier field (EnforcedDirichlet) because −U depends on an unknown. The tip is stationary in the computational frame.

In the axisymmetric window the tip is not held still. We use the same device (one global unknown, one point constraint, residual fed into an EnforcedBC), but the residual is

rtip − X = 0  cartesian measure
LaTeX 
r_{\mathrm{tip}} - X = 0
\quad\text{(cartesian measure; not }2\pi r\text{)}

so X is the moving hole radius. We caution that writing the planar residual rtip = 0 would be wrong twice. The tip sits at R0 > 0, and under the 2πr measure that constraint is a double root with a vanishing Jacobian row. The pin is therefore written in the cartesian measure so the row stays O(1) rather than growing like 2πR(t).

The far edge is not Dirichlet. The residual form is

rfar − (X+L) = 0
LaTeX 
r_{\mathrm{far}} - (X+L) = 0
\quad\text{(EnforcedBC residual, not Dirichlet)}

At the far/interface corner, the free-surface kinematic multiplier must be pinned (DirichletBC(_kin_bc=0)). Otherwise two multipliers act on one free mesh_x and the Jacobian is exactly singular.

The design note originally listed the window as a fallback if the graded annulus could not reach the desired tend. It is now a first-class sibling of axisymmetric_lab.py. A shifted-metric co-moving variant, with a measure that depends on a global unknown, was assessed and rejected. It would route azimuthal curvature, the quantity under study, through unexercised custom machinery.
